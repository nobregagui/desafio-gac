# Finance App 💸

Aplicação de exemplo para controle de saldo, depósitos, transferências e reversões de transações entre usuários.

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- JSON Server (para simular a API)

## 📦 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

- Node.js (v16 ou superior)
